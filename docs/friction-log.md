# AfterWard friction log

Built 31 Aug to 23 Oct 2026. Team: Charvi Maurya (developer), Shilpa Agarwal (mentor).
First time using AWS and building a voice agent.

Ordered by impact: patient safety first, then what shaped the product and the AWS build, then
smaller tooling issues. Everything here was found by building and testing the working app with
synthetic discharge letters. Where it says "fixed", the fix has automated tests (925 Python tests,
76 web tests).

## Top 3 suggestions
1. **Alexa+:** open the MCP Toolkit to hackathon teams. Our MCP server already works; the only part we had to simulate is Alexa+ itself, and browser speech recognition is the weakest part of the voice experience, especially for the short answers older patients give.
2. **Amazon Bedrock tool use:** make "answer only after retrieval" easy to enforce, so a health assistant can never say "your letter doesn't say" without having looked. Today this needs app-side checks and a second model call.
3. **Amazon Bedrock extraction:** report the text a structured extraction did not map to any field. In a discharge letter, a dropped phone number is a safety gap, not a formatting issue.

## What worked well
- **S3 → SQS → Lambda → Bedrock** turned an uploaded letter into a ready plan in about 15 seconds, with a clear log line for every stage (received, extracted, checked, saved, indexed, ready) and no patient details in the logs.
- **EventBridge Scheduler** ran the reminder check every five minutes with no errors.
- **ECS on Fargate** kept the MCP server running without a restart since 13 Oct.
- **S3 Vectors** with a patient filter returned the right passage of the right patient's letter, with its page number, so every answer can show its evidence.
- **Safety replies built in code, not by the model:** symptoms are answered only with the letter's own warning signs, word for word, so the most important replies are predictable.
- **Open source:** the letter validator became a standalone package, [discharge-letter-check](https://github.com/charvimaurya/discharge-letter-check), which AfterWard now uses.
- **Automated tests** caught every regression while fixing the items above: each fix added a test with the patient's exact words.
